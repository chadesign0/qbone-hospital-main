# 큐본병원 메인페이지

피그마 `tsffnUtYgfqgdsSRRHZ5n7 / 962:40`와 제공된 이미지로 구현한 반응형 메인페이지입니다.

## 실행

Node.js가 설치된 환경에서 이 폴더를 열고 `npm run dev`를 실행한 뒤 http://127.0.0.1:5173 에 접속합니다. 패키지 설치나 빌드가 필요하지 않습니다. 정적 호스팅에는 `dist` 폴더 내용을 사용합니다. `dist/index.html`을 직접 열어서 확인할 수도 있습니다.

## 수정 위치

- `dist/index.html`: 메인 문구, 진료시간, 주소, 전화번호 및 메뉴
- `dist/styles.css`: 레이아웃, 색상, 글꼴 및 모바일 화면. navbar 높이는 PC·모바일 모두 80px입니다.
- `dist/app.js`: 전체 메뉴, 페이지 검색, 의료진 전환, 이미지 확대 및 안내창
- `dist/assets`: 실제 사용 이미지, 아이콘 및 로컬 웹폰트

navbar는 첫 화면에서 메인 이미지 위의 캡슐형으로 표시되며, 히어로 영역이 화면 위로 완전히 지나가면 약 0.95초 동안 흰 배경만 대칭으로 확대됩니다. 헤더와 내부 로고·메뉴·버튼은 처음부터 같은 위치에 고정되어 전환 중 재배치되거나 위로 이동하지 않습니다. 맨 위로 복귀하면 캡슐형으로 돌아오고, 모바일 전체 메뉴의 위치도 전환 상태와 관계없이 유지됩니다.

대표전화는 요청에 따라 02.2234.8580으로 통일했습니다. 진료시간은 상단 시안을 기준으로 적용했습니다. 예약·상담의 실제 온라인 주소는 제공되지 않아 전화 안내를 표시합니다. 회원가입·로그인, 공지·후기 상세, 약관·개인정보처리방침·비급여 상세 페이지와 서버 기능은 이번 메인페이지 작업에 포함되지 않습니다. 두 번째·세 번째 의료진의 상세 프로필은 제공된 시안에 없어 진료 일정 문의로 안내합니다.

## 확인

1920px PC 및 390px 모바일 화면에서 전체 구조, 이미지 로딩, 가로 넘침, 전체 메뉴, 페이지 검색, 의료진 전환, 예약 안내와 이미지 확대를 확인했습니다. 추가 요청인 navbar 80px은 1440px PC와 390px 모바일에서 실제 렌더링 높이를 확인했습니다.

의료진 영역은 전영식 → 신동협 → 백운영 순서로 순환합니다. 다음 화살표를 누르면 오른쪽 미리보기 카드가 메인으로 이동하며 컬러로 바뀌고, 기존 메인 카드는 오른쪽 끝 미리보기로 돌아가며 흑백으로 바뀝니다. 모바일에서는 페이지 슬라이드와 선택 점으로 전환합니다.

병원 공간 영역은 이미지 양끝 중앙의 이전·다음 버튼으로 넘기는 4장 슬라이드입니다. 하단 선택 점 4개는 현재 슬라이드와 연동되며 점을 눌러서도 전환할 수 있습니다. 배경은 1920px 화면 기준 너비 1240px, 높이 503px이고, 선택 점은 시안처럼 사진 왼쪽 아래의 흰 여백에 위치합니다. 추가 사진 전달 전까지 제공된 동일 공간 사진을 네 슬라이드에 임시 적용했습니다. 각 `.space-slide img`의 이미지 주소를 교체하면 됩니다. 이미지 클릭 확대 기능은 이 영역에서 제거했습니다.

모바일 의료진 영역은 기존처럼 소개글 왼쪽·사진 오른쪽 배치를 유지합니다. 사진 너비를 220~250px로 조금 확대하고 오른쪽 음수 여백을 없애 왼쪽으로 옮겼습니다. 섹션 높이와 의료진 전환 방식은 기존과 같습니다.
